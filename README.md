# LEARNING-GIT-

#important terminologies to remember

pwd - shows current directory 
<br>
mkdir - creates a directory
<br>
cd - changes directory
<br>
cd .. - moves to parent directory
<br>
ls - lists files and folders
<br>
git init - initialising a git repo
<br>
git status - shows repo status
<br>
git add - stores changes
<br>
git commit - saves a version of changes
<br>
